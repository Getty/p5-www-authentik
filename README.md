# WWW-Authentik

Perl client for the [authentik](https://goauthentik.io/) identity provider: OIDC against
an application plus the REST API (v3), a structural sibling of `WWW::Keycloak`.

**Status: skeleton.** Nothing is implemented yet.

Async twin: `Net::Async::Authentik`.
